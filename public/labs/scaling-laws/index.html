Scaling Laws 实验室

参数、数据、算力三者之间的账：要做多少次运算，钱该花在模型上还是数据上，把推理算进去以后又该怎么配。每个数字都在页面里真实算出来。

016ND 算力计算器

训练时每个 token 要做三件事：前向，每个参数一次乘法一次加法，\(2N\) 次运算；反向传给上一层，又是 \(2N\)；反向算每个参数的梯度，再 \(2N\)。读了 \(D\) 个 token，总运算就是

\[ C \approx 6ND \]

总运算除以显卡每秒能做的运算，就是要跑多少秒。显卡不会一直跑满峰值，实际用上的比例叫利用率（MFU）。所以卡时 = \(C \div (\text{峰值} \times \text{利用率}) \div 3600\)，再除以卡数就是要训多少小时。

选一个公开模型，或者自己拖 \(N\) 和 \(D\)。有官方卡时的模型，下面第三根条是官方数字，可以和算出来的对照。

–总运算 C（FLOPs）
–按所选利用率的卡时
–用这么多卡要训
–官方卡时反推的利用率

注意看：Llama-3-8B 按 40% 利用率算约 51 万卡时，官方是 130 万卡时；6ND 是「最少要做的运算」，真实账单常常是它的 2–3 倍。

02对数坐标下的幂律

Kaplan 等人 2020 年发现，损失随参数量按幂律下降：

\[ L(N) = \left(\frac{N_c}{N}\right)^{\alpha}, \qquad N_c = 8.8 \times 10^{13} \]

他们测出 \(\alpha \approx 0.076\)。把 \(N\) 换成 \(10N\)，括号里的数变成原来的 \(1/10\)，损失就乘 \(10^{-\alpha}\)，和从哪个 \(N\) 开始无关。两边取对数：\(\ln L = \alpha \ln N_c - \alpha \ln N\)，以 \(\ln N\) 为横轴、\(\ln L\) 为纵轴，就是一条斜率为 \(-\alpha\) 的直线。

拖 \(\alpha\)，在普通坐标和对数坐标之间切换。橙色三角形标出参数乘 10 时损失降了多少。

–L(1B)
–L(10B)
–参数每乘 10，损失乘
–损失降一半，参数要乘

注意看：在对数坐标里，不管 α 是多少都是直线，α 只改变斜率；在普通坐标里，变化全挤在最左边。

03给定算力，拖参数量

Chinchilla 把损失写成三项：去不掉的部分 \(E\)、模型太小的代价、数据太少的代价：

\[ L(N, D) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}} \]

算力 \(C\) 固定时，选定 \(N\) 就定了 \(D = C / (6N)\)，损失只剩 \(N\) 一个变量。\(N\) 太大，数据不够；\(N\) 太小，模型不够。令导数为 0 得到谷底：

\[ N_{\text{opt}} = \left(\frac{\alpha A}{\beta B}\right)^{\frac{1}{\alpha+\beta}} \left(\frac{C}{6}\right)^{\frac{\beta}{\alpha+\beta}} \]

默认算力是 Chinchilla 与 Gopher 的预算 \(5.76 \times 10^{23}\) FLOPs。拖 \(N\) 看点在 U 形上走，拖算力看谷底移动。系数可以在 Besiroglu 等人 2024 年的重新拟合和 Hoffmann 等人原论文之间切换。

两项之和 L − E模型太小 A/Nα数据太少 B/Dβ
–这个 N 能读的 token
–每参数 token
–损失 L
–最优 N / D
–最优每参数 token

注意看：用重新拟合的系数，算力从 1020 拖到 1026，最优每参数 token 只在 16–23 之间变；切到原论文那组系数，同样的预算给出约 59，而且随算力明显变大，和论文自己用另外两种方法得出的约 20 对不上，这正是它被重新拟合的原因。

04把推理算进去

模型上线后，每生成一个 token 要做一次前向，约 \(2N\) 次运算。设一生要生成 \(D_{\text{推}}\) 个 token，训练加推理的总运算是

\[ C_{\text{总}} = 6 N D_{\text{训}} + 2 N D_{\text{推}} \]

定一个要达到的损失：Llama-3-8B 的配置（8.03B 参数、15 T token）在实验 03 的公式（重新拟合系数）里的值 2.0218。对每个 \(N\)，从 \(L(N, D_{\text{训}}) = 2.0218\) 反解出需要的训练数据，再算总运算。蓝线是总运算，灰虚线是其中的训练部分，橙虚线是推理部分。

总运算训练推理● 最省的点
–最省的 N
–它要的训练 token
–每参数 token
–Llama-3-8B 比最优多花

注意看：不算推理时最优就是 Chinchilla 比例（约 19 个/参数），8B 要多花几倍；推理拖到 1014 附近，最优落到 8B 左右，每参数上千个 token。曲线左端在约 5B 处竖起来：再小的模型，读多少数据也到不了这个损失。

05涌现与度量

设模型每个答案 token 猜对的概率 \(p\) 随规模平稳上升（示意：每个 token 的损失 \(\ell = c\,N^{-k}\)，取 \(10^8\) 时 \(\ell = 1.2\)、\(10^{11}\) 时 \(\ell = 0.02\)，\(p = e^{-\ell}\)）。答案有 \(L\) 个 token，三种打分：

  • 全对才算对：各 token 独立时，得分是 \(p^{L}\)。
  • token 准确率：平均每个 token 对不对，就是 \(p\)，和 \(L\) 无关。
  • 编辑距离：平均错几个 token，是 \(L\,(1-p)\)，图上画成「错的个数」，越低越好。

拖答案长度、切换打分方式。灰线一直是每个 token 的 \(p\)，作为对照。

–N = 109 时得分
–N = 1010 时得分
–得分从 10% 升到 90% 跨了

注意看：模型没变，只换打分方式。「全对」下答案越长，曲线越陡、起跳点越靠右；token 准确率和编辑距离始终平滑。
