Agent Loop 实验室

一个 Agent 就是模型 + 工具 + 一个 while 循环。下面把这个循环拆开，一圈一圈地看它在做什么、花了多少 token、在哪里停下来。

00最小的 Agent Loop，一步一步播

任务：比较两个城市现在哪个更热。工具只有一个 get_temperature(city)。左边是循环本身，右边是真实格式的消息数组：每转一圈，数组就长两条。这里的「模型」是页内规则模拟的（它的思考是写死的模板，不是真的大模型），温度来自页内的一张假数据表，不是实时天气。

messages 数组（每次调模型都把它整个发过去）

0循环转了几圈
1消息条数
–数组总字符数（JSON）

注意看：模型从来不「执行」工具，它只是输出一条 tool_use；执行的是循环外面的程序（harness），再把 tool_result 追加回数组。模型什么时候不再输出 tool_use，循环就在什么时候退出。

01上下文每圈变长，发送总量二次方增长

每次调模型都要把整个 messages 数组重新发一遍。设第一圈发 c0 个 token，之后每圈多出一条工具结果（k 个）和一条模型输出（m 个），那么第 i 圈发送的长度是 c0 + (i − 1)(k + m)，n 圈的总发送量：

Σ = n c0 + (k + m) · n(n − 1)/2

有 prompt cache 时，前一圈已经发过的前缀只按折扣价计，只有新追加的 k + m 个 token 按原价。

无 cache有 cache（计价当量）

每一步发送的上下文长度（token）

累计发送（无 cache）与计价当量（有 cache）

–最后一步的上下文长度
–无 cache：累计发送 token
–有 cache：计价当量
–cache 省下的比例

固定 c0 = 800、每步模型输出 m = 80。步数翻一倍，累计发送量约翻四倍。价格比例 0.1 只是占位：各家 API 对 cache 命中的折扣不同，按你用的那家改这个滑块。这里没有算 cache 写入的额外费用。

02终止条件：循环在哪里停下

循环有三种退出方式：模型给出最终回答（正常）、达到最大步数、花完 token 预算。拖「任务需要的工具调用数」看正常情况；勾上「模型卡住」，模型每一圈都还想再调一次工具，看两个兜底哪个先把它拦下来。每步追加的 token 数沿用 01 的设定（c0 = 800，每步 +480）。

横轴：第几圈；纵轴：到这一圈为止累计发送的 token。三条竖线是三种退出条件各自会在哪一圈触发

–循环停在第几圈
–停止原因
–停下时累计发送 token
–如果没有任何兜底

最大步数是按「圈」拦，预算是按「钱」拦。因为上下文是二次方增长的，预算这条线往往比你以为的来得早：把预算放到 300k、步数放到 40，看预算在第几圈比最大步数先触发。

03工具会失败：三种处理策略的成功率

任务需要连续调 N 次工具，每次调用独立地以概率 p 失败（超时、报错、返回空）。三种策略：直接放弃（任何一次失败整个任务失败）；把错误回给模型重试（错误信息作为 tool_result 追加回去，模型再试，最多重试 R 次）；换工具（失败后改用一个备用工具，它自己的失败率是 q，只换一次）。下面是 20000 次蒙特卡洛模拟，细线是解析解。

–直接放弃：成功率
–回填重试：成功率
–换工具：成功率
–平均工具调用次数（放弃 / 重试 / 换工具）

解析解：放弃 (1 − p)N；重试 (1 − pR+1)N；换工具 (1 − pq)N。重试几乎总是最划算的兜底，代价是多花几圈、多发几次上下文。

04Workflow 还是 Agent：步数的分布

同一个任务「查 N 个城市的温度并比较」，两种做法。Workflow：代码写死步骤，不管问题里有没有现成信息，一律查 N 次再比较，永远 N + 1 步。Agent：模型自己决定下一步，题目里已经给了温度的城市它会跳过，但每次查完也可能多走一步（再确认一次、或者先调错了工具）。下面是规则模拟的 5000 个任务。

Workflow 的步数、成本、延迟都是常数，可预测；Agent 平均可能更省，但有一条长尾。Anthropic 的建议是：能用 workflow 的就别用 agent，只有当下一步真的得看情况决定时才让模型来决定。

05读一条 ReAct 轨迹

ReAct 的轨迹就是 Thought / Action / Observation 三种行交替。点任意一行，看它对应循环里的哪个环节、在消息数组里是什么角色。

点左边的一行。

Thought 和 Action 是同一次模型输出里的两部分（先想再做），Observation 是 harness 执行工具后追加的。一组 Thought → Action → Observation 就是循环的一圈；最后一个 Action 是 Finish，循环退出。
