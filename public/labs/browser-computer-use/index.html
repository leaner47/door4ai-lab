浏览器与电脑操作实验室

AI 看网页、点按钮、操作电脑，说到底还是工具调用：模型输出一条指令，外面的程序替它执行，再把结果交回来。下面的「商城」是页面里一个真实的 1280 × 800 网页，读文字、建元素清单、找坐标、执行点击、检测注入，都是真的在它上面做。

00同一个网页，三种「看」法

Agent 看网页有三种方式：读出页面上的文字；读一份可交互元素清单（可访问性树，每个元素带一个编号，之后可以按编号点它）；或者看一张截图。前两种是文字，用分词器数 token；截图按 Claude 的规则计费：每 28 × 28 像素算一个视觉 token，超过上限先缩小。

01看着截图点一下：坐标要换算

  
截图给模型之前通常要缩小（太大的截图 API 会直接拒绝，而且更贵）。模型在缩小后的图上说「点 (x, y)」，程序得把这个坐标换算回屏幕上的位置再去点。在下面的图上点一下，你就是模型；看程序按三种方式换算后，点击实际落在哪里。屏幕是 2 倍的高清屏：逻辑尺寸 1280 × 800，物理像素 2560 × 1600。

02三种「动手」方式，遇到网页改版

  
任务：「在搜索框里输入耳机，点搜索」。同一个任务有三种做法：在页面里运行一段 JavaScript（按元素的 id 找到它）；按元素清单里的编号操作；按截图上的坐标点击和打字。下面三种做法都在模拟网页上真实执行，执行完检查页面上是否真的出现了搜索结果。再勾上几种常见的网页变化，看哪种做法会坏。

  

    

      
      
      
      
    

    

    
注意看：没有哪种做法永远最好。按 id 的脚本最快最省，但页面一改版就找不到元素；按编号操作每次都重新读清单，不怕改版，但一个没有文字的按钮在清单里只剩「button」，模型认不出；按坐标点击能看懂图标，却怕「截图和点击之间页面动了」。实用的 Agent 三种都有，按情况换着用。

  






  
03谁来拦住它：一层一层的权限

  
能动手的 Agent 需要好几层保护，每一层管一类风险：只能访问授权的网站；付款、发布、提交个人信息前要问人；只能读写授权的文件夹；删除文件要单独同意；所有命令都在一台隔离的虚拟机里跑。点一下每层的开关，看 8 个动作分别被哪一层拦下。

04网页里藏着的指令：提示注入

  
对 Agent 来说，网页内容是数据，不是命令。但模型读到的都是文字，坏人可以把一句「指令」藏在网页里：白底白字、极小的字号、图片的替代文字、被隐藏的区块。下面这句话被藏进了商城的评论区。改藏法、改措辞，看它从哪条通道进入模型、规则检测器能不能认出来。
