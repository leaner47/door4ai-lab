LayerNorm · RMSNorm · Pre-Norm · 尺度漂移

LayerNorm 实验室

深网络里每一层的数字大小会随层数漂移。下面每个向量、每个梯度都是浏览器里真实算出来的。

00把一个向量拉回同一把尺子

一个 token 在某一层是一个向量，这里取 8 维。LayerNorm 对它做三件事：减去这 8 个数的均值，除以它们的标准差，再逐维乘 γ 加 β。拖动「整体放大」和「整体平移」改变输入，看输出动不动。

输入 x（纵轴随数据缩放）

输出 γ · (x − μ) / σ + β

–输入均值 μ
–输入标准差 σ
–输出均值
–输出标准差

不管输入整体放大多少倍、平移多少，输出一动不动：均值永远是 β，标准差永远是 γ。放大和平移这两个自由度被抹掉了，网络要表达的信息都在各分量的相对大小里。

01残差流越加越大

残差那一讲说过，Transformer 的每一层都往主干上加一个修正量：h ← h + F(h)。这里用随机矩阵真实地算 64 维向量一路往下走的范数（长度）：F(h) = W · ReLU(h)，W 的大小用「分支增益」控制，增益 1 表示分支输出和输入差不多长。三种做法：不做 Norm；Pre-Norm 把 Norm 放在分支里（h + F(Norm(h))）；Post-Norm 把 Norm 放在主干上（Norm(h + F(h))）。

不做 NormPre-NormPost-Norm

横轴：第几层；纵轴：‖h‖（对数坐标）

–不做 Norm：第 L 层 ÷ 第 0 层
–Pre-Norm：第 L 层 ÷ 第 0 层
–Post-Norm：第 L 层 ÷ 第 0 层

不做 Norm 时，分支的输出跟着输入一起变大，于是范数按指数增长：增益 1 时每层乘约 √2，32 层后是几万倍。Pre-Norm 让每层分支看到的都是一样长的向量，加上去的量固定，主干只按 √L 慢慢长。Post-Norm 每层都把主干重新拉回来，范数不变。

同一层里的不同 token 也不在一把尺子上。把 256 个随机初始化的 token 向量（64 维）送进同一个不做 Norm 的残差流，看走到第 L 层时它们的范数分布；第二张图是同一批向量经过 LayerNorm 之后、真正送进分支的长度。

每个 token 走的 ReLU 路径不一样，范数像随机游走一样越走越散：32 层后最长和最短的差几十倍。同一个矩阵 W 要同时伺候这些长短悬殊的向量，没法用同一组参数做好；LayerNorm 之后它们长度全部相等，只剩方向不同。

03LayerNorm 还是 RMSNorm

RMSNorm 比 LayerNorm 少做一步：不减均值，直接除以均方根 RMS = √(mean(x²))，也没有 β。还是实验 00 那个 8 维向量，拖动它的均值，看两种结果差多少。

输入 x

LayerNorm：(x − μ) / σ

RMSNorm：x / RMS(x)

–均值 μ
–标准差 σ
–均方根 RMS
–两种结果最大差异

RMS² = σ² + μ²。均值为 0 时两者一模一样；均值越偏，RMSNorm 的输出被整体压得越小，但各分量的相对大小不变。Llama、Qwen、Gemma 这些模型用 RMSNorm：少算一次均值，效果不差。

04Norm 放在哪：梯度的量级

反向传播那一讲说过，学习率乘的是梯度。这里用一个 16 维、L 层的小残差网络真实反向传播一次（刚初始化，任务和残差那讲一样是拟合一条曲线），比较三种设计里每一层权重 W 的梯度有多大。「分支增益」和实验 01 相同。

横轴：第几层；纵轴：‖∂L/∂Wl‖（对数坐标）

–不做 Norm：第 1 层梯度
–Pre-Norm：第 1 层梯度
–Post-Norm：第 1 层梯度
–Post-Norm 直达通路的增益 ∏ 1/σ

不做 Norm 时，梯度跟着实验 01 里的范数一起漂：层数或增益一变，梯度就差几个数量级，昨天调好的学习率今天就不能用。两种 Norm 都把梯度压回同一个量级。区别在直达通路：Pre-Norm 的主干不经过任何变换，从输出到第 1 层始终有一条增益为 1 的路；Post-Norm 的主干每层都被除以一次 σ，这条路的增益是 ∏ 1/σ，层数一多就指数级消失，梯度只能靠一层层分支接力。

05没有 Norm 时，学习率的可用范围

同一个小网络、同一个任务，用带动量的 SGD 训练 200 步，7 档学习率各试一遍。换层数和分支增益，看哪些学习率能把误差压到 0.1 以下，哪些直接发散。

–不做 Norm：可用学习率
–Pre-Norm：可用学习率
–Post-Norm：可用学习率

不做 Norm 时，可用的学习率范围随层数和分支增益剧烈移动，增益 1、16 层时一档都不剩；有 Norm 时，不管分支多大、多少层，可用范围基本停在同一个位置。这就是「同一把尺子」的意思：学习率可以统一定，不用每换一种网络就重新摸索。这个小网络里 Post-Norm 并不吃亏，它的麻烦出在几十层以上的大模型里（见实验 04）。
