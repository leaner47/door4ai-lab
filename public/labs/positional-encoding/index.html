位置编码实验室

还是注意力一讲那四个 token：粮油、店、买了、小米。打乱它们，看注意力分不分得清；再把 q 和 k 转起来。每个数字都在页面里真实算出来。

01打乱词序

「小米」固定在最后（位置 3），前面三个词可以任意排列。每个词的向量 \(x\)、三个矩阵 \(W_Q\)、\(W_K\)、\(W_V\) 都和注意力一讲相同。「小米」用自己的 \(q\) 和每个词的 \(k\) 做点积得到分数 \(s\)，除以 \(\sqrt 2\) 后做 softmax 得到份额 \(w\)，再算 \(x' = x + \sum w\,v\)。

三种做法：不加位置；加位置向量，每个词先加上所在位置的 \(p\)（文章第二步那张表）；RoPE，位置 \(m\) 上的 \(q\)、\(k\) 转 \(m \times 10°\)。换几种词序，看右边的 \(x'\) 动不动。灰色虚线箭头是原句「粮油 店 买了 小米」的 \(x'\)。

–「粮油」分到的份额

不加位置时，六种词序的距离全是 0：份额只是跟着词换了行。加位置向量或 RoPE 之后，换一种顺序，x′ 就变。RoPE 下「粮油」离「小米」越近，分到的份额越大（这一组数字恰好如此，训练出来的模型不一定）。

02正弦位置编码

第 \(i\) 对数是同一个角度的 \(\sin\) 和 \(\cos\)，角度是 \(\omega_i \cdot \text{pos}\)，转速 \(\omega_i = b^{-2i/d}\)。原论文 \(b = 10000\)。热力图每一行是一个位置的编码，每一列是一维：蓝色为正，橙色为负，越深绝对值越大。下面一排圆盘是其中 8 对在选定位置上的指针。

两个位置的编码做点积，每一对贡献 \(\sin a \sin(a+b) + \cos a \cos(a+b) = \cos b\)（\(a = \omega_i\,\text{pos}\)，\(b = \omega_i k\)），所以 \(\operatorname{PE}(\text{pos}) \cdot \operatorname{PE}(\text{pos}+k) = \sum_i \cos(\omega_i k)\)，只取决于相隔几格 \(k\)。拖「位置」，看右下角的点积变不变。

03RoPE 旋转盘

只看一对数。「小米」的 \(q = (1.0,\ -0.6)\) 在位置 \(m\)，转 \(m\theta\)；「粮油」的 \(k = (1,\ -1)\) 在位置 \(n\)，转 \(n\theta\)。两个箭头的夹角是旋转前的 \(14.04°\) 加上 \((m - n)\theta\)，分数是

\[ q_m \cdot k_n = \lVert q \rVert\,\lVert k \rVert \cos\big(14.04° + (m - n)\,\theta\big) = 1.649\,\cos\big(14.04° + (m - n)\,\theta\big) \]

左边是旋转盘：虚线是旋转之前，实线是旋转之后。右边是分数随位置差 \(m - n\) 的曲线，橙点是当前位置差。点「一起往后挪」，两个位置同时加 1：两个箭头都在转，夹角和分数不变。

04多频率叠加

真实的 \(q\)、\(k\) 有 \(d\) 个数，分成 \(d/2\) 对，第 \(i\) 对的转速是 \(\theta_i = b^{-2i/d}\)。为了只看位置的作用，假设每一对的 \(q\)、\(k\) 都同向、长度为 1，这时第 \(i\) 对贡献 \(\cos\big((m-n)\,\theta_i\big)\)，总分除以对数后，在位置差为 0 时是 1。

05超出训练长度

\(d = 128\)，64 对。训练时输入最长 \(L\) 个 token，第 \(i\) 对最多转过 \((L-1)\,\theta_i\)。灰色细柱是训练时转过的圈数，彩色粗柱是测试长度 \(T\) 下（按所选办法改过转速之后）转过的圈数，纵轴是对数刻度，虚线是一圈。训练时没转满一圈、测试时又转得比训练时更远的对，会遇到没见过的角度，标成橙色。

记 \(s = T / L\)。位置插值：每一对转速除以 \(s\)。NTK-aware：底数换成 \(b\,s^{d/(d-2)}\)。YaRN：按训练时转过的圈数 \(r\) 分段，\(r < 1\) 的除以 \(s\)，\(r > 32\) 的不动，中间线性过渡。Llama 3.1：按 8192 分段，转一圈少于 2048 个位置的不动，多于 8192 的除以 8，中间平滑过渡（这一项固定用它自己的配置：\(b = 500000\)，\(L = 8192\)）。
