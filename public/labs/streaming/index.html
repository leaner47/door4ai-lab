流式输出实验室

回答为什么一个字一个字蹦出来，以及前端要怎么接住它。下面的流都在页面里用定时器真实推送、真实解析，切 token 用的是真实分词器。

00流式与非流式：什么时候看到第一个字

同一个请求，服务器端做的事完全一样：排队、把整段 prompt 读一遍（prefill）、然后一个 token 一个 token 地生成（decode）。区别只在于什么时候把结果交给你：非流式等最后一个 token 生成完才一次性返回，流式每生成一点就推一点。

TTFT ≈ 排队 + prompt token 数 ÷ prefill 速度　　总时长 ≈ TTFT + (输出 token 数 − 1) ÷ decode 速度

–流式：看到第一个字（TTFT）
–非流式：看到第一个字
–两者看到完整回答
–流式让第一个字提前了

两条线的终点永远对齐：流式不让模型算得更快，只是把等待从「整段时间」压缩成「TTFT」。拉长输出长度，非流式的空白跟着变长，流式的首字纹丝不动；拉长 prompt，两者的首字一起往后推。

01SSE 报文：一个不关闭的 HTTP 响应

流式响应用的是 SSE（Server-Sent Events）：服务器回一个 Content-Type: text/event-stream 的响应，但不马上结束，而是一段一段往里写文本。每个事件是几行 字段: 值，最常见的是一行 event: 和一行 data:，事件之间用一个空行分开。

点「开始」，左边是服务器写出的原始文本，右边是解析器从里面切出来的事件，以及把文字增量拼起来的结果。可以切换 Anthropic 和 OpenAI 两种格式。
