注意力实验室：Q、K、V 到底在干什么

「我在粮油店买了两斤小米」和「我在数码店买了一部小米」，同一个「小米」，模型怎么知道一个是粮食、一个是手机？八个实验，从一个点积讲到真实模型里的 28 层注意力。

00同一个「小米」，两种意思

句子进入模型，先被切成 token，每个 token 查表得到一个向量（embedding）。查表只看 token 本身，不看上下文，所以两句话里的「小米」拿到的是同一个向量。

这个向量里两种意思都有。在 Qwen3-0.6B 的词表里找和「小米」最像的向量，前几名一半是粮食，一半是科技公司：

01回头看：前面每个词分几成

注意力做的事可以先用一句话说完：「小米」回头看前面每个词（也看自己），给每个词分一个份额，份额加起来是 100%；再按份额从每个词那里拿一点信息，加到自己身上。生成式模型只能往前看，不能看后面还没出现的词。

两句话里，这个头都把最大的一份给了店名（「粮油」「数码」）。份额是怎么算出来的？这就是 Q 和 K 的工作。

02为什么不直接比词向量：相似不等于有用

最直接的想法：「小米」的向量和谁像，就多看谁。可是最像「小米」的永远是它自己，其次是「大米」这种近义词。「小米」需要的不是和它长得像的词，而是能告诉它"我是哪个小米"的词，比如店名。

所以每个词先用两个矩阵把自己的向量 \(x\) 变成两个新向量：

\[ q = W_Q\,x \qquad k = W_K\,x \]
  • \(q\)（query，查询）：我在找什么线索？「小米」的 \(q\) 大致在问"前面有没有说明我用途的词"。
  • \(k\)（key，键）：我能提供什么线索？「粮油」「数码」的 \(k\) 大致在说"我是一个场所的类别"。

打分时拿查询去对键，而不是拿向量去对向量。\(W_Q\)、\(W_K\) 一开始是随机数，在训练中慢慢调成这样；所有 token 共用同一套 \(W_Q\)、\(W_K\)。

上面一行：「小米」的嵌入向量和每个 token 的余弦相似度，第一名是它自己。下面一行：第 1 层第 11 个头用 \(q\cdot k\) 算出的份额，第一名是店名。两行都是 Qwen3-0.6B 的真实数据。

第 1 层里，两个「小米」的 \(q\) 完全相同两句话里「小米」的向量一样、位置也一样（都是第 7 个 token），所以算出的 \(q\) 一模一样（实测最大差值 0）。它要找的线索没变，变的是前面那些词的 \(k\)：一句里是「粮油」，一句里是「数码」。

03点积：查询和键对上了没有

打分用点积：两个向量对应位置的数相乘，再全部加起来。两个方向越一致，点积越大；方向垂直时为 0；方向相反时为负。

\[ \begin{aligned} q\cdot k &= q_1k_1 + q_2k_2 + \cdots + q_dk_d \\ &= \lVert q\rVert\,\lVert k\rVert\cos\theta \end{aligned} \]

下面用文章里的算例（4 个 token，每个向量 2 个数）。橙色是「小米」的 \(q = (1.0,\ -0.6)\)，蓝色是每个词的 \(k\)。转动 \(q\)（长度不变），看谁的分数最高。

04softmax：分数变份额，为什么不只给第一名

点积有正有负、大小不一，要换成加起来等于 1 的份额。用的是 softmax：先取指数（全变成正数，并放大差距），再除以总和。

\[ w_i = \frac{e^{s_i}}{\sum_{j} e^{s_j}} \]

既然要找最相关的词，为什么不干脆把 100% 都给分数最高的那个？有两个原因。第一，线索常常不止一个：「粮油」和「店」合起来才说明是粮油店。第二，训练靠梯度：把某个分数调大一点，份额要跟着变大一点，模型才知道往哪调。只给第一名的话，分数小小地变化，结果纹丝不动，梯度是 0。

05除以 \(\sqrt{d_k}\)：真实的分数有多大

二维里点积很小。真实模型里 \(q\)、\(k\) 是 \(d_k\) 维的，Qwen3-0.6B 每个头 \(d_k = 128\)，128 个乘积加起来，分数能到几百。这是第 1 层第 11 个头里「小米」的真实分数：

—最大份额

关掉缩放：分数之间相差几十，softmax 几乎把 100% 都给了第一名，又回到了"只给第一名"，梯度消失。打开缩放，份额才分散开。

为什么偏偏除以 \(\sqrt{d_k}\)？假设 \(q\)、\(k\) 的每个分量都是均值 0、方差 1 的随机数，每个乘积 \(q_ik_i\) 的方差也是 1，\(d_k\) 个加起来，方差就是 \(d_k\)：

\[ \operatorname{Var}(q\cdot k) = d_k \qquad \operatorname{std}(q\cdot k) = \sqrt{d_k} \]
\[ \operatorname{std}\!\left(\frac{q\cdot k}{\sqrt{d_k}}\right) = 1 \]

维度越高，分数散得越开；除以 \(\sqrt{d_k}\) 正好把散开的幅度拉回 1。下面用真的随机向量验证：

06\(v\)：拿走的是内容，而且是加上去

份额算好了，从每个词那里拿走什么？不是它的 \(k\)。每个词还要用第三个矩阵算出值向量 \(v\)（value），这才是真正交出去的内容：

\[ v = W_V\,x \]
为什么 \(k\) 和 \(v\) 要分开？想想图书馆：\(k\) 是书脊上的分类标签，你靠它决定拿哪本；\(v\) 是书里的内容，你真正读进去的东西。"我是场所类别"适合用来匹配，但「小米」真正需要的是"这里卖粮食"或"这里卖电子产品"。

把每个词的 \(v\) 乘上它的份额再全部加起来，得到修改量 \(\Delta x\)，然后加到「小米」原来的向量上（残差连接）：

\[ \Delta x = \sum_{j} w_j\,v_j \qquad x' = x + \Delta x \]

数字和文章第七、八步相同：横轴「像手机」，纵轴「像粮食」。灰色是 \(x = (0.5,\ 0.5)\)；蓝色是各词的 \(w_j v_j\)，首尾相接；橙色是加完之后的 \(x' \approx (0.74,\ 1.66)\)。份额是除以 \(\sqrt{2}\) 之后的那组。在实验 03 里转动 \(q\)，这里的份额和 \(x'\) 会跟着变。

从第 4 层起，大多数头把一半以上的份额给了句子的第一个 token。它几乎不带信息，像一个"停车位"：一个头这次没找到想要的线索，就把份额停在那里，这个现象叫 attention sink。真正的线索散落在少数几个头里。

合起来：缩放点积注意力

把所有 token 的 \(q\)、\(k\)、\(v\) 按行叠成矩阵 \(Q\)、\(K\)、\(V\)，上面的步骤就是《Attention Is All You Need》（2017）里的这一行：

\[ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V \]
  • \(QK^{\top}\)：每个查询和每个键做点积，得到分数（实验 03）。
  • \(\div\sqrt{d_k}\)：把分数散开的幅度拉回 1（实验 05）。
  • \(\operatorname{softmax}\)：分数变成加起来等于 1 的份额（实验 04）。
  • \(\times V\)：按份额把值向量加起来，再加回原向量（实验 06）。

\(Q\)、\(K\)、\(V\) 都来自同一句话，是这句话自己看自己，所以叫自注意力。一个头只找一种线索，真实模型里每层有很多个头一起工作（下一讲），后面再接一个 MLP（再下一讲）。
