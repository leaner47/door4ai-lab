梯度下降实验室

模型训练就是在一片看不见的地形上找最低点。下面每一步都是浏览器里真实算出来的。

01看斜率，往下走一步

横轴是一个参数 x，纵轴是损失 L。你站在曲线上某一点，看不到整条曲线，只知道脚下的斜率 L′(x)。规则只有一条：

x ← x − η · L′(x)

斜率为正，说明往右是上坡，就往左走；斜率为负就往右走。η 叫学习率，决定一步迈多大。点曲线可以换出发点。

–位置 x
–损失 L(x)
–斜率 L′(x)
–下一步移动 −η·L′
0已走步数

越靠近谷底斜率越小，步子会自己变小，不用人去刹车。在「起伏」上从右边出发，会停在右边那个小坑里：梯度只看脚下，看不到远处更深的谷。

02学习率：太小、刚好、太大

换成最简单的碗 L = ½ a x²，斜率是 a x，每走一步 x 被乘上同一个数 (1 − ηa)。这个乘数的绝对值小于 1 才会收敛，所以学习率有一条硬上限 η < 2 / a。a 是曲率：碗越陡，能用的学习率越小。

η 刚好等于 1 / a 时一步到位；在 1 / a 和 2 / a 之间会左右来回、越摆越小；超过 2 / a 每一步都冲过头更远，损失指数爆炸。

03两个参数：梯度是一支箭

有两个参数时，损失是一片地形，图里颜色越浓的地方越低。梯度 ∇L 是两个偏导数排成的向量，指向上坡最陡的方向，并且总是垂直于等高线；梯度下降沿 −∇L 走。点图换出发点，三种走法同时出发：

  • 普通梯度下降：只看当前梯度。
  • Momentum：带惯性，速度 = 0.9 × 上一步速度 + 当前梯度。
  • Adam：再给每个参数单独按梯度的大小缩放步长。

「窄谷」里一个方向陡、一个方向缓：普通梯度下降的学习率被陡的方向卡住，只能在谷壁之间来回弹，沿谷底挪得很慢。「香蕉谷」（Rosenbrock 函数）里它 3000 步都到不了终点，惯性和自适应步长的价值就在这里。

04真的训练一个模型：拟合一条直线

下面 40 个点是按 y = 1.5x + 1 加上随机噪声生成的。模型是 ŷ = w x + b，只有 w、b 两个参数；损失是均方误差 MSE，即所有点的误差平方取平均。两个偏导数：

∂L/∂w = 2 · 平均(e · x)　　∂L/∂b = 2 · 平均(e)　　（e = ŷ − y）

左边看直线怎么被一步步「拉」到数据上，右边看同一过程在 (w, b) 损失地形里的路线。十字是最小二乘公式直接解出的最优点。

05一次看多少数据：全量、小批量、SGD

真正的模型训练数据有几万亿个 token，每走一步都把全部数据算一遍不现实。做法是每次随机抽一小批（batch）算梯度，用它代替全量梯度。下面 200 个点，同样的学习率 0.01，四种 batch 大小花同样多的计算（按「看过的样本数」算）：

batch = 1 每看一个样本就走一步，路线最抖，同样的计算量却走得最远，只是到了谷底也停不稳，一直在最优点附近晃；全量梯度方向最准，2000 个样本却只够走 10 步。实际训练取中间：小批量既有足够多的步数，又能让 GPU 一次并行算一批。
