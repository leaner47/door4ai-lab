## 一句话版本

把损失的计算过程画成一张图，每个节点是一步简单运算。前向时从输入算到损失，顺手记下每个节点对自己输入的**局部导数**；反向时从损失出发，沿着图倒着走，每过一个节点就把手里的梯度乘上它的局部导数、交给前面。走到头，损失对每个参数的梯度全部到手，而且只走一趟。这就是反向传播，PyTorch 里 `loss.backward()` 做的就是这件事。

## 计算图：把公式拆成一串小步骤

梯度下降那一讲默认「梯度能算出来」，残差那一讲用到了「每层导数连乘」，这一讲把中间这块补上。

先看一个不是神经网络的例子：<i>y</i> = (<i>a</i>·<i>b</i> + <i>c</i>)²。它可以拆成三步：

<p class="formula"><i>u</i> = <i>a</i>·<i>b</i>　　<i>v</i> = <i>u</i> + <i>c</i>　　<i>y</i> = <i>v</i>²</p>

每一步只做一件事，而且每一步对自己的输入求导都是初等的：乘法对 <i>a</i> 的导数是 <i>b</i>，加法的导数是 1，平方的导数是 2<i>v</i>。把这三步按数据流向画出来，就是一张**计算图**。前向沿着箭头算：<i>a</i> = 2，<i>b</i> = 3，<i>c</i> = 1 时，<i>u</i> = 6，<i>v</i> = 7，<i>y</i> = 49。

<figure class="clip"><video src="/videos/backpropagation/ChainRule.webm" poster="/videos/backpropagation/ChainRule.png" controls loop muted playsinline preload="metadata"></video></figure>

反向从 <i>y</i> 出发，手里拿着 ∂<i>y</i>/∂<i>y</i> = 1。退回到 <i>v</i>，乘上这条边的局部导数 2<i>v</i> = 14，得到 ∂<i>y</i>/∂<i>v</i> = 14。再退回到 <i>u</i>，加法的局部导数是 1，所以 ∂<i>y</i>/∂<i>u</i> = 14。最后退到 <i>a</i>，乘上 <i>b</i> = 3，得到 ∂<i>y</i>/∂<i>a</i> = 42。这就是链式法则：

<p class="formula">∂<i>y</i>/∂<i>a</i> = (∂<i>y</i>/∂<i>v</i>) · (∂<i>v</i>/∂<i>u</i>) · (∂<i>u</i>/∂<i>a</i>) = 2<i>v</i> · 1 · <i>b</i> = 42</p>

要点有三个。第一，每个节点只需要知道两样东西：后面传来的梯度，和自己在前向时记下的局部导数，乘一下交出去，不需要知道整张图长什么样。第二，局部导数里用到的值（比如 <i>b</i> 的值、<i>v</i> 的值）都是前向算过的中间结果，所以**前向必须把中间值存下来**，这就是训练比推理吃显存的原因之一。第三，如果一个节点的输出被用了两次，反向时两条路传回来的梯度要**相加**（多元链式法则）。实验 00 可以一步一步看这个过程。

## 一个两层网络，完整手算一遍

换成真正的网络：输入 2 维，隐藏层 3 个单元，输出 1 个数。

<p class="formula"><i>z</i> = <i>W</i><sub>1</sub><i>x</i> + <i>b</i><sub>1</sub>　　<i>h</i> = ReLU(<i>z</i>)　　<i>ŷ</i> = <i>W</i><sub>2</sub><i>h</i> + <i>b</i><sub>2</sub>　　<i>L</i> = ½(<i>ŷ</i> − <i>y</i>)²</p>

共 13 个参数：<i>W</i><sub>1</sub> 是 3×2，<i>b</i><sub>1</sub> 是 3 个，<i>W</i><sub>2</sub> 是 1×3，<i>b</i><sub>2</sub> 是 1 个。取一个样本 <i>x</i> = (1, 2)，目标 <i>y</i> = 1，参数取：

<p class="formula"><i>W</i><sub>1</sub> = [[0.5, −0.3], [−0.2, 0.4], [0.1, 0.1]]，<i>b</i><sub>1</sub> = (0.2, 0, −0.5)，<i>W</i><sub>2</sub> = [0.8, −0.5, 0.3]，<i>b</i><sub>2</sub> = 0.1</p>

**前向**：<i>z</i> = (0.1, 0.6, −0.2)；过 ReLU，<i>h</i> = (0.1, 0.6, 0)，第三个单元被截成 0；<i>ŷ</i> = 0.08 − 0.30 + 0 + 0.1 = −0.12；<i>L</i> = ½(−1.12)² = 0.6272。

<figure class="clip"><video src="/videos/backpropagation/Backward2Layer.webm" poster="/videos/backpropagation/Backward2Layer.png" controls loop muted playsinline preload="metadata"></video></figure>

**反向**，从损失往回：

1. 损失对输出：<i>δ</i> = ∂<i>L</i>/∂<i>ŷ</i> = <i>ŷ</i> − <i>y</i> = −1.12。
2. 输出层参数：<i>ŷ</i> = <i>W</i><sub>2</sub><i>h</i> + <i>b</i><sub>2</sub>，对 <i>W</i><sub>2</sub> 的第 <i>j</i> 个元素求导就是 <i>h<sub>j</sub></i>。所以 ∂<i>L</i>/∂<i>W</i><sub>2</sub> = <i>δ</i>·<i>h</i> = (−0.112, −0.672, 0)，∂<i>L</i>/∂<i>b</i><sub>2</sub> = <i>δ</i> = −1.12。
3. 传回隐藏层：∂<i>L</i>/∂<i>h</i> = <i>δ</i>·<i>W</i><sub>2</sub> = (−0.896, 0.56, −0.336)。
4. 过 ReLU：<i>z</i> &gt; 0 的位置导数是 1，否则是 0。第三个单元 <i>z</i><sub>3</sub> = −0.2，于是 ∂<i>L</i>/∂<i>z</i> = (−0.896, 0.56, **0**)。传到它的 −0.336 在这里被截断。
5. 第一层参数：<i>z<sub>i</sub></i> = Σ<sub><i>j</i></sub> <i>W</i><sub>1,<i>ij</i></sub> <i>x<sub>j</sub></i> + <i>b</i><sub>1,<i>i</i></sub>，所以 ∂<i>L</i>/∂<i>W</i><sub>1,<i>ij</i></sub> = (∂<i>L</i>/∂<i>z<sub>i</sub></i>) · <i>x<sub>j</sub></i>：

   <p class="formula">∂<i>L</i>/∂<i>W</i><sub>1</sub> = [[−0.896, −1.792], [0.56, 1.12], [0, 0]]，∂<i>L</i>/∂<i>b</i><sub>1</sub> = (−0.896, 0.56, 0)</p>

6. 如果还想往前传（比如前面还有一层）：∂<i>L</i>/∂<i>x</i> = <i>W</i><sub>1</sub><sup>T</sup>(∂<i>L</i>/∂<i>z</i>) = (−0.56, 0.4928)。

一次前向、一次反向，13 个梯度全有了。每一步都只是「上游梯度 × 局部导数」，没有任何一步需要整体推导。第三个单元那一行全是 0，说明这一步里连着它的 3 个参数学不到任何东西，这就是 ReLU 的「死单元」问题的由来。实验 02 用的就是这组数字，可以随意改，并和数值微分逐项对照。

## 矩阵形式：<i>Wx</i> + <i>b</i> 的梯度是外积

上面第 2 步和第 5 步有同一个结构。一层 <i>z</i> = <i>Wx</i> + <i>b</i>，上游传来 <i>δ</i> = ∂<i>L</i>/∂<i>z</i>（和 <i>z</i> 同形状），那么：

<p class="formula">∂<i>L</i>/∂<i>W</i> = <i>δ</i> <i>x</i><sup>T</sup>　　∂<i>L</i>/∂<i>b</i> = <i>δ</i>　　∂<i>L</i>/∂<i>x</i> = <i>W</i><sup>T</sup><i>δ</i></p>

第一个是**外积**：<i>δ</i> 是列向量（输出维），<i>x</i><sup>T</sup> 是行向量（输入维），乘出来正好是和 <i>W</i> 同形状的矩阵，第 (<i>i</i>, <i>j</i>) 个元素是 <i>δ<sub>i</sub> x<sub>j</sub></i>：这个权重把输入 <i>x<sub>j</sub></i> 送进输出 <i>z<sub>i</sub></i>，它的梯度就是「输入有多大」乘「输出端要改多少」。第三个式子说明梯度往前传要乘 <i>W</i> 的转置：前向用 <i>W</i> 把输入维映到输出维，反向用 <i>W</i><sup>T</sup> 把梯度从输出维映回输入维。一批样本时把 <i>x</i> 和 <i>δ</i> 都换成矩阵（每列一个样本），公式不变，外积自动变成对整批求和。

所以一层的反向只是两次矩阵乘法（算 <i>δx</i><sup>T</sup> 和 <i>W</i><sup>T</sup><i>δ</i>），和前向那一次矩阵乘法的规模相同。这就是为什么**反向的计算量约等于前向的两倍**。

## 为什么反向只需要一次

如果不会反向传播，最直接的办法是数值微分：把某个参数加一点点 <i>h</i>，重新前向算一遍损失，看损失变了多少，(<i>L</i>(<i>w</i> + <i>h</i>) − <i>L</i>(<i>w</i> − <i>h</i>)) / 2<i>h</i> 就是梯度的近似。它简单、可靠，所以是检验反向传播实现有没有写错的标准办法（实验 02 就是这么做的）。但每个参数要做两次前向，13 个参数做 26 次，80 亿个参数做 160 亿次，哪怕一次前向只要 1 ms 也要几百年。

自动微分还有一种「前向模式」：在前向计算的同时把导数一起算出去。它是精确的，但一趟只能算出所有输出对**一个**输入的导数，代价同样正比于参数个数。

反向模式反过来：一趟算出**一个**输出对所有输入的导数。训练时输出只有一个（损失是一个数），输入有几十亿个（参数），所以反向模式一趟就够，代价不随参数个数增长。这是反向传播被选中的全部理由。把「前向 + 反向 ≈ 3 次前向」和「一次前向每个参数约 2 次浮点运算」合起来，就是常说的训练每个 token 约 6<i>N</i> 次浮点运算。实验 03 可以拖参数个数看这个差距。

## autograd 做的就是这个

PyTorch、JAX 这些框架的核心叫 autograd（自动微分）：你用普通的运算写出损失，框架在后台把每一步运算记成计算图的节点，并把反向需要的中间值存起来；调用 `loss.backward()`，它就按拓扑逆序走一遍图，每个节点做「上游梯度 × 局部导数」再累加到输入上，最后每个参数的 `.grad` 里就是梯度。优化器再拿这些梯度做上一讲的更新。

这件事本身很小。Andrej Karpathy 的 micrograd 用约 100 行 Python 写出了一个完整的标量版 autograd，实验页里的那个也只有几十行 JavaScript：一个节点类，加、减、乘、幂、ReLU、tanh 六种运算，每种运算记下自己的局部导数，再加一个按拓扑逆序乘加的 `backward`。实验 02 里的 13 个梯度、实验 04 里 500 个节点的长链，都是它算的。真正的框架在这之上做的是张量化、GPU 上的核函数、显存管理，原理没有变。

## 实验里讲了什么

0. **一个表达式的计算图**：<i>y</i> = (<i>a</i>·<i>b</i> + <i>c</i>)²，一步一步看前向值和反向梯度怎么流，点任一节点看它收到什么、乘了什么、交出去什么。
1. **一条链**：<i>y</i> = tanh(2<i>x</i> + 1)²，拖 <i>x</i> 看三段局部导数和它们的乘积，和曲线切线的斜率、数值微分三者一致；tanh 饱和时整条链的梯度接近 0。
2. **两层小网络**：2 → 3 → 1，默认就是文中手算的那组数，可以改任何参数、换激活函数；13 个梯度与数值微分逐项对照，差在 10⁻⁹ 以下；ReLU 把负的 <i>z</i> 那一路截断。
3. **为什么反向只需要一次**：数值微分、前向模式、反向传播需要的前向次数随参数个数怎么变，有 GPT-2、Llama-3 的真实参数量可以直接点。
4. **深链里的连乘**：把链拉到 100 层，普通链每层乘 <i>g</i>，残差链每层乘 1 + <i>g</i>，用同一个自动微分器算梯度传回第 1 层还剩多少。

## 和前后两讲的关系

梯度下降那一讲讲了拿到梯度以后怎么更新参数；这一讲讲梯度是怎么算出来的。残差那一讲里「每层导数连乘」的公式，在这里就是反向传播沿着一条链走过去的样子，实验 04 直接把它接上了。下一讲讲 LayerNorm：知道了梯度是前向中间值和局部导数的乘积，就能理解为什么把每层的输入拉回同一个尺度，对训练深网络和反向传播本身都是必需的。
