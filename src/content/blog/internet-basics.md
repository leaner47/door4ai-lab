## 一句话版本

**网络只认 IP 地址，人只记域名，DNS 负责把域名翻译成 IP，路由器负责把数据一站一站送到那个 IP。** 你的手机先通过家里的路由器出门（路由器把家里所有设备的内网地址换成同一个公网地址，叫 NAT），再经过运营商的网络、国际出口和海底光缆，到达服务器。

## 实验里讲了什么

1. **距离就是延迟。** 光在光纤里每毫秒只走约 204 公里。上海到洛杉矶直线一万多公里，光就算走直线，一个来回也要 100 毫秒以上，这是物理上限。
2. **IP 与 NAT。** IPv4 只有约 43 亿个地址，不够分。家里设备用内网地址（`192.168.x.x`），出门时路由器换成同一个公网地址并记在表里。这也是外面没法主动连进你家电脑的原因。
3. **DNS 逐级查询。** 浏览器 → 系统 → 递归解析器 → 根服务器 → `.com` 服务器 → 域名的权威服务器。答案带一个 TTL，在这段时间里各级都直接用缓存。
4. **路由。** 每台路由器只知道「去某个地方交给哪个邻居」。实验里可以挖断线路，看路由自动绕路，再点开每个节点的路由表。
5. **DNS 污染。** 普通 DNS 查询是明文。中国大陆国际出口处的防火长城设备看到被封锁域名的查询，会抢先伪造回复；它离你更近，假答案先到，电脑就用了假的。换 8.8.8.8 躲不过，加密 DNS 能防伪造但知名服务器本身被封，代理软件的 fake-ip 则干脆不在本地查。
6. **来回次数。** 打开网页要先 TCP 握手、再 TLS 握手、再发请求，每步至少一个来回。RTT 乘以来回次数，就是你等待的主要时间。CDN 和新协议都是在减少这个乘积。
