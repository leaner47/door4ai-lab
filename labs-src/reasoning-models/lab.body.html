01直接答与分步答（示意）

这是一个玩具模型，只有一条规则：每生成一个 token 做一次前向计算，一次前向计算最多做一步运算，而且只能用已经写在纸面上（题目里或前面写出来的 token 里）的数。真实模型一次前向能做的事多得多，但同样有上限：层数是固定的。

直接答时，答案是读完题后的第一个 token，只有一次计算，只来得及做第一步，后面几步来不及做。分步答时，每一步的结果先写出来，下一步从纸面上读它。拖「步数」把题目变长，点「下一个 token」一个一个生成。

02多数投票计算器

同一道题采样 \(k\) 条推理，每条答对的概率是 \(p\)，各条互相独立。\(k\) 条里恰好 \(i\) 条答对的概率是二项分布：

\[ P(i) = \binom{k}{i}\, p^{i}\,(1-p)^{k-i} \]

「错答案都相同」是最坏情况：只有对、错两种答案，答对的条数超过一半就赢，正好一半抛硬币。「错答案各不相同」时，对的答案只要出现 2 次以上就是最多的；只出现 1 次时所有答案各 1 票，随机挑中对的概率是 \(1/k\)。

03best-of-N 与有噪声的验证器

采样 \(N\) 个回答，每个答对的概率是 \(p\)。验证器给每个回答打分，选分最高的。这里的验证器模型：看起来对的回答平均得 \(d\) 分，看起来错的平均得 0 分，再加上标准正态噪声。\(d\) 越大，验证器越分得清。另外，错答案里有比例 \(q\) 看起来也对（验证器被骗），同样平均得 \(d\) 分。

曲线是蒙特卡洛模拟（每个点 4000 次，种子固定）。点「抽一组」看一次具体的挑选：每个点是一个回答，横坐标是验证器给的分。

04思考的成本

思考 token 和回答 token 一样按输出 token 计费，一样要一个一个生成。每次费用 = 输入 token × 输入价 + （思考 token + 回答 token）× 输出价；等待时间 = 首个 token 前的等待 + （思考 token + 回答 token）÷ 生成速度。价格按每百万 token 计，默认值是示意，按你用的模型改。

05固定预算：大模型少想，还是小模型多想（示意）

大模型的参数是小模型的 \(M\) 倍，生成一个 token 的钱也是 \(M\) 倍。预算用「够大模型答几次」来量：预算 \(b\) 时，大模型答 \(b\) 次投票，小模型答 \(Mb\) 次投票。两个模型的单次答对率是你设的（示意），投票正确率用实验 02 的二项分布真算（错答案都相同的最坏情况）。

06强化学习让思考变长（示意）

把模型的「思考长度」简化成 5 档：200、400、800、1600、3200 个 token。想得越长越容易答对，但收益递减（下面第一行数字，示意）。模型一开始偏爱短的。每一步训练：出 16 道题，每道采样一组 8 个回答，答对奖励 1、答错 0，再减去长度惩罚 \(\lambda \times\) 长度 / 3200；组内算优势 \(A_i = (r_i - \bar r)/\sigma\)，按后训练那一讲的 GRPO 更新：

\[ z_k \leftarrow z_k + \eta \cdot \frac{1}{G}\sum_{i} A_i\,\big([\,y_i = k\,] - p_k\big) \]

奖励里从没提过「要想得长」。点「训练 50 步」，看平均长度和正确率怎么变。
